CineMood - Intelligent Movie Recommendation Engine

An interactive, object-oriented console application built in Java that allows users to search, filter, and dynamically expand a local movie catalog.

## Key Engineering Features
* Unified Single Search Bar: Evaluates both Title and Genre simultaneously within a single input stream.
* Smart Insertion Pipeline: Detects failed queries and dynamically prompts the user to add missing titles while validating data inputs.
* Stream Buffer Cleaning: Implements low-level pipeline management to prevent Java Scanner \n input skips.
* Multi-Layered Filtering: Combines text matching and numerical rating preferences using complex conditional tracks.

##  Tech Stack
* Language: Java (JDK 17+)
* Data Structure: Dynamic Core Array Lists
* I/O Management: Java Utility Scanner Stream
